# Changelog

## 0.1.0-rc.2 — Public Alpha RC

- Unified distribution version, project Schema version `2.0`, and product stage
  `public_alpha`.
- Added a single `VERSION` source and consistent CLI / migration metadata.
- Removed the obsolete software-version project field from migrated output
  while retaining read compatibility for legacy projects.
- Added real UI/API delivery acceptance evidence for the controlled SaaS case.

This release is a Public Alpha Release Candidate. Future release stages are
planning only and are not part of this release process.
