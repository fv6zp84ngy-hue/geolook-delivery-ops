# Tester Guide

1. Extract the ZIP into a new directory.
2. Run `bash run_tester_smoke.sh`.
3. Run `bash serve_public_demo.sh` and open the printed local URL.
4. Record observations in `TESTER_FEEDBACK_TEMPLATE.md`.

The kit is intentionally offline. A successful smoke run proves the package
boundary and deterministic demo; it does not claim a production deployment.
